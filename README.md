# one-liner-laughs-01

A single original one-line joke for make.fun's One-Liner Laughs bounty. `line.ts` holds the line; `main.ts` writes it, with no trailing newline, to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (default `output`).
